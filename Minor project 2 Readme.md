# Car Price Prediction using Linear Regression

## 📌 Project Overview

This minor project focuses on predicting car prices using Machine Learning. Exploratory Data Analysis (EDA) and Multiple Linear Regression are used to understand the dataset and build a prediction model.

## 🎯 Objectives

* Analyze the car dataset using Exploratory Data Analysis.
* Identify important features affecting car prices.
* Visualize relationships between variables.
* Build a Multiple Linear Regression model.
* Evaluate the performance of the model.

## 📊 Dataset

The project uses the **Car Details v3** dataset.

Dataset source: Kaggle

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🔍 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Data Preprocessing
6. Train-Test Split
7. Multiple Linear Regression
8. Model Evaluation
9. Visualization
10. Conclusion

## 📈 Model Evaluation

The model is evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
